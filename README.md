# D-ingetin

> Biar hidup gak semuanya diingat sendiri.

D-ingetin adalah aplikasi reminder dan kolaborasi kehidupan sehari-hari yang membantu individu, keluarga, pasangan, dan tim kecil mengelola berbagai aktivitas penting melalui reminder, notifikasi, dan fitur berbagi pengingat.

## Problem

Semakin dewasa, semakin banyak hal yang harus diingat:

- Bayar tagihan
- Servis kendaraan
- BPJS
- Janji temu
- Follow up pekerjaan
- Meeting tim

Banyak orang mengalami mental load yang tinggi karena harus mengingat semuanya sendiri.

## Solution

D-ingetin membantu pengguna:

- Membuat reminder
- Berbagi reminder
- Menugaskan reminder
- Berkolaborasi dengan keluarga atau tim
- Mendapatkan notifikasi pengingat

## Core Features

### Reminder
- Daily Reminder
- Weekly Reminder
- Monthly Reminder

### Diingetin Bareng
- Shared Reminder
- Invite Member
- Shared Workspace

### Assignment
- Assign reminder ke anggota lain
- Reminder status
